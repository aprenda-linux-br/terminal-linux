# Aula 02 — Primeiros Passos no Terminal Linux

Nesta aula começamos o contato prático com o terminal Linux utilizando o Ubuntu.

A proposta é mostrar que a interface gráfica e o terminal são formas diferentes de interagir com o mesmo sistema.

Para isso, usamos o comando `ls` e comparamos o conteúdo exibido no terminal com os arquivos e diretórios visualizados no gerenciador de arquivos do Ubuntu.

## O que vamos estudar

- o que é uma janela de terminal;
- diferença entre terminal e shell;
- como interpretar elementos básicos do prompt;
- usuário e nome da máquina;
- diretório home do usuário;
- significado do `~` no prompt;
- primeiro contato com o comando `ls`;
- comparação entre interface gráfica e terminal.

## Conceito importante

O terminal é uma interface baseada em texto utilizada para interagir com o sistema.

O shell é o programa que recebe a linha de comando digitada pelo usuário, interpreta sua estrutura e inicia os programas solicitados.

Um exemplo comum de shell no Linux é o Bash.

Nesta aula utilizamos:

```bash
ls
```

O comando `ls` é utilizado para listar o conteúdo de um diretório.

Quando executamos `ls` sem informar outro caminho, ele lista o conteúdo do diretório atual.

Se o terminal estiver aberto na home do usuário, veremos através do terminal muitos dos mesmos diretórios que também aparecem no gerenciador de arquivos.

## Interface gráfica x Terminal

Na interface gráfica, os diretórios aparecem como pastas e ícones.

No terminal, eles aparecem como nomes em texto.

Por exemplo:

```bash
ls
```

Pode exibir algo semelhante a:

```text
Desktop  Documents  Downloads  Music  Pictures  Videos
```

A informação pertence ao mesmo sistema de arquivos.

O que muda é a forma utilizada para visualizar e interagir com ela.
