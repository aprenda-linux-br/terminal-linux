# Aula 02 — Primeiros Passos no Terminal Linux

Nesta aula começamos o contato prático com o terminal Linux.

O objetivo é entender os elementos básicos que aparecem na tela antes de começar a trabalhar com comandos.

## O que vamos estudar

- o que é uma janela de terminal;
- o que é o shell;
- como interpretar o prompt;
- usuário;
- nome da máquina;
- diretório atual;
- diferença entre usuário comum e root;
- símbolos `$` e `#`.

## Conceito importante

O terminal é a interface utilizada para interagir com o sistema por meio de texto.

O shell é o programa que recebe e interpreta os comandos digitados pelo usuário.

Um exemplo comum de shell no Linux é o Bash.
